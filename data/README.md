# Dataset provenance

`emails.csv` contains 30 fictional examples written for this portfolio repair with Codex assistance. They are not exported from an inbox and contain no real contact details or private messages. They replace the earlier dataset, whose origin was undocumented and which contained an invalid Markdown fence row.

Category has 10 examples each of Work, Personal, and Spam. Priority is manually assigned High, Medium, or Low. All Spam examples are Low; that simplified labeling rule can make priority evaluation artificially easy. The examples are demonstrations, not a benchmark representative of real email.

No external dataset was downloaded. Do not use the reported results to claim validated production spam detection or reliable personal priority judgments.
